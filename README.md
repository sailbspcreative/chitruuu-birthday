# 💖 Chitruuu's 21st Birthday Web Application 🎂✨

An interactive, aesthetic birthday gift web app created especially for **Chitruuu** (Born 3rd September 2005).

## 🌟 Key Features
- 💌 **Landing Invitation Card**: Glassmorphic pass screen with glowing 3D heart.
- 🐻 **Bubu & Dudu Evasive "No" Button**: Interactive evasive runaway button with playful toast notifications.
- 🎂 **Interactive Candle Blow-Out**: Candle extinguishing flames, sound FX, and confetti cannon.
- 📸 **Polaroid Photo Wall & Uploader**: Memory gallery with real photos of Chitruuu and instant browser photo uploader.
- ⏳ **Life Ticker**: Live real-time counter since 3rd September 2005.
- 💌 **Secret Envelopes**: Hidden birthday wishes and editable notes.
- 🏮 **Sky Lantern Wishes & WhatsApp Forwarding**: Launches glowing sky lanterns and sends wishes directly to WhatsApp!
- 🥳 **Grand Final Celebration**: Fireworks show and Birthday Queen card.

## 🛠️ Built With
- React 18
- Vite
- Tailwind CSS
- Web Audio API
- Canvas Confetti
- Lucide Icons
